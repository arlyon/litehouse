# Litehouse Web

Greenfield `litehouse-web` implementation for Cloudflare Workers. This package does not migrate or reuse the legacy Next.js Cockpit, its authentication, transport, routes, or state. It is a nested pnpm workspace with its own lockfile so its optional peers cannot alter the legacy site's dependency graph.

The current root route is an implementation gate for the nine exact-major capability renderers. It uses local view-model fixtures only and has no account, server connection, network, or command authority.

## Design system

`vendor/open-design/litehouse/` is a closed snapshot of the Litehouse Open Design package. `src/tokens.css` is the sole adapter from canonical Open Design tokens into the local `--lh-*` namespace; product styles consume only those aliases. `vendor/open-design/litehouse.lock.json` records every file hash and the bundle digest.

```bash
pnpm bundle:check
```

The lock also records the reviewed Open Design package digest. After deliberately reviewing and replacing the snapshot, update that digest in the checker and regenerate the lock with `pnpm bundle:write`; an ordinary check never rewrites provenance.

## Validation

From this directory:

```bash
pnpm typecheck
pnpm test
pnpm test:worker
pnpm build
pnpm deploy:dry-run
pnpm check
```

From the repository root, use `pnpm --dir web check`.

`src/routeTree.gen.ts` is generated by the TanStack Start Vite plugin and must not be edited manually. No deployment command is provided by this tranche.
